1. Jelaskan apa yang dimaksud dengan dokumen root?*  
Dokumen root adalah direktori utama tempat file-file website disimpan di server web. Saat seseorang mengakses server melalui browser (misalnya http://localhost), server akan mencari file di dalam dokumen root untuk ditampilkan.  

2. Pada Apache web server, apakah dokumen root harus terletak dalam direktori C:\xampp\htdocs? Jelaskan jawaban Anda. 
Tidak harus. Secara default, Apache dalam XAMPP menggunakan C:\xampp\htdocs sebagai dokumen root. Namun, kita bisa mengubah lokasi dokumen root dengan mengedit file konfigurasi Apache (httpd.conf) dan mengatur direktori lain sebagai dokumen root.  

3. Jelaskan apa yang dimaksud dengan perintah Git berikut:  
- git init → Membuat repository Git baru di dalam folder project.  
- git clone → Mengunduh (menyalin) repository yang sudah ada dari GitHub ke komputer lokal.  
- git remote → Menghubungkan repository lokal dengan repository di GitHub.  
- git add → Menambahkan file ke dalam staging area sebelum commit.  
- git commit → Menyimpan perubahan ke dalam repository lokal dengan pesan tertentu.  
- git push → Mengunggah perubahan dari repository lokal ke repository GitHub.  
- git checkout → Berpindah antara branch dalam repository.  

4. Jelaskan perbedaan antara GitHub dan GitLab.  
- GitHub → Platform hosting Git yang lebih populer, dengan komunitas yang besar dan banyak digunakan untuk proyek open-source.  
- GitLab → Alternatif GitHub dengan fitur tambahan seperti CI/CD (Continuous Integration/Continuous Deployment) yang lebih lengkap, serta bisa di-hosting secara mandiri.  

5. Apa bedanya variabel user dengan variabel sistem?  
- Variabel user → Variabel yang dibuat dan didefinisikan oleh pengguna dalam kode PHP, misalnya:  
  php
  $nama = "Budi";
  $umur = 20;
    
- Variabel sistem → Variabel yang sudah didefinisikan oleh sistem PHP dan berisi informasi tentang server, misalnya:  
  php
  echo $_SERVER["PHP_SELF"]; // Menampilkan nama file yang sedang diakses
    

6. Apa persamaan variabel sistem dengan variabel konstanta? 
- Persamaan → Keduanya sudah didefinisikan sebelumnya dan nilainya bisa diakses langsung dalam program.  
- Perbedaan:  
  - Variabel sistem → Bisa berubah nilainya tergantung kondisi server.  
  - Variabel konstanta → Nilainya tetap dan tidak bisa diubah setelah didefinisikan, misalnya:  
    php
    define('PHI', 3.14);
